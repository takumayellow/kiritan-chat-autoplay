# 東北きりたんのキャラクター設定の調査

会話用のペルソナ（`core/kiritan_core.py` の `KIRITAN_PERSONA_TEMPLATE`）を書き直すときに、公式の設定と、
ファンの間で定着しているイメージを確かめた。2026年10月に調べた結果をまとめる。

## 公式の設定

| 項目 | 内容 | 出典 |
|------|------|------|
| 年齢・学年 | 11歳、小学五年生（ふるさと女学院初等部） | 東北ずん子公式「キャラクター紹介」 |
| 誕生日 | 2月13日 | 同上 |
| 趣味 | ずん子、ゲーム、ひきこもること、同人誌漁り、弓道部所属 | 同上 |
| 身長 | 135cm | VOICEVOX 寮のキャラクターページ |
| 特技・必殺技 | ゲーム／きりたん砲 | 同上 |
| 性格 | ひきこもり気質で夜型の生活をしている。他人に対してはクールで毒舌 | 同上 |
| 一人称・二人称 | わたし／あなた | VOICEVOX 寮「呼び方」 |
| 姉の呼び方 | ずん子（17歳）は「ずんねえさま」、イタコ（19歳）は「イタコねえさま」 | 同上 |
| 姉からの呼ばれ方 | ずん子からは「きりたん」、イタコからは「きりちゃん」 | 同上 |
| 声の印象 | 落ち着いていながらも可愛らしい声 | AHS 製品ページ |

- 公式の年齢は11歳。14歳とする資料は見つからなかった。旧ペルソナが「14歳」としていたのは誤り。
- VOICEVOX 寮のページは「設定は自由に改変してよい」としている。会話では、公式設定と矛盾しない範囲で使う。

## ファンの間で定着しているイメージ（非公式）

ピクシブ百科事典、アニヲタWiki、各種まとめに共通して書かれている。公式の設定ではないので、口調の参考に留める。

- 淡々とした丁寧語で話す。セリフの頭に「――」を付けて書かれることが多い。
- しっかり者でませている一方、「クソガキ」扱いされることもある。姉たちへのツッコミ役になりやすい。
- 姉が好き（シスコン）。面倒くさがり。おばけが苦手。
- 東北や秋田の話題は、きりたんぽにちなむ程度で、口調に方言は特に無い。

## ペルソナへの反映

| 調べた内容 | 反映 |
|------------|------|
| 11歳・小学五年生 | 年齢を11歳に直した。小学生なので、理大祭の ITC の部員ではないとした（`line_bot/context.py`） |
| クールで毒舌、淡々とした丁寧語 | 「です・ます調の落ち着いた丁寧語」「はしゃがない」「軽い毒はよいが相手を傷つけない」 |
| ゲーム、夜型、ひきこもり、弓道部 | 話題の種（`core/kiritan_dialogue.py` の `TOPIC_SEEDS`）に入れた |
| ずんねえさま・イタコねえさま | 姉の呼び方を固定した。姉との出来事を話題の種に入れた |
| 一人称「わたし」 | そのまま採用 |
| 二人称「あなた」 | 公式の二人称だが、会話で何度も使うと不自然になるので、名前を知らないうちは呼びかけを省く |
| 方言は無い | 「東北の話は自然なときだけ」とした。毎回の東北アピールはしない |

## ガイドラインで禁止されていること

東北ずん子のキャラクター利用ガイドラインと音源の利用規約で禁止されている内容。会話でも扱わない。

- 公序良俗に反するもの、キャラクターのイメージを著しく損なうもの
- 政治・宗教の支持や批判
- 個人・団体・国の批判や誹謗中傷
- 嘘やフェイク（実在しない情報を事実として伝えること）
- 情報商材、風俗、反社会的勢力に関わるもの

11歳の設定なので、性的な話題も避ける（ガイドラインの明示ではなく、こちらの判断）。
VOICEVOX の音声を使うときは「VOICEVOX:東北きりたん」のクレジットが要る。

## 確かめられなかったこと

- 公式の口癖や決め台詞は見つからなかった。ファンの間の「――」や「おみそ撃ちますよ」は二次創作由来とみられるので、ペルソナには入れていない。
- 好きなゲームの具体的なタイトルは公式に無い。会話ではタイトルを作らないようにしている。
