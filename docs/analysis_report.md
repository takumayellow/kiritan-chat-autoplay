## 会話ログ分析

**ソース:** `conversation_log.txt`（1,287行、CLI ターミナルセッション記録）

### セッション数

合計 **15 セッション** が記録されている（`=== 会話スタイルを選びましょう ===` の出現回数に基づく）。
ただし一部はスタイル選択直後に終了した短命セッションを含む。

### 会話スタイルの選択傾向

| スタイル | 選択回数 | モデル |
|----------|----------|--------|
| ライト雑談（軽め） | 5回 | gpt-4o-mini |
| ゆったり会話（丁寧） | 1回 | o4-mini |
| じっくり深掘り（教授モード） | 7回 | o4-mini-high |
| デフォルト（Enter のみ） | 2回 | gpt-4o-mini |

「じっくり深掘り」が最多で、高い推論能力を求める利用傾向が見られる。

### ユーザープロフィール

セッションごとに設定されたプロフィール:

| 呼び名 | ジェンダー | 年齢感 | セッション数 |
|--------|-----------|--------|-------------|
| イエローさん | 男性 | 20代 | 3 |
| あなた（未設定） | 未設定 | 未設定 | 7 |
| ゲスト | 未設定 | 未設定 | 1 |
| yuulisさん | 男性 | 学生 | 1 |
| 山田さん | 未設定 | 未設定 | 1 |

未設定（スキップ）が約半数を占め、プロフィール入力は任意性が高い。

### 入力モードの利用

- **テキスト入力**: 全セッションで利用
- **マイク入力 (mic)**: 複数セッションで利用。音声認識の誤認識（外国語として認識される問題）が散見される
- **text モードから Enter で音声入力**: 後期セッション（Phase 3 の改善後）で利用

### 会話トピック（抜粋）

- 偏微分方程式の解法（微分方程式、変数分離法）
- 日本の祭り（祇園祭、天神祭）
- 東北三姉妹（東北ずん子、東北イタコ、東北きりたん）
- 日常的な挨拶・雑談

### エラー・問題点

| 種別 | 回数 | 内容 |
|------|------|------|
| マイク文字起こし失敗 | 2回 | `Audio file might be corrupted or unsupported` (400 エラー) |
| 音声認識の誤認識 | 複数回 | 日本語が外国語（ルーマニア語、ロシア語、ポーランド語、ポルトガル語等）として認識される |
| コマンド誤入力 | 1回 | PowerShell で `c` を実行して CommandNotFoundException |

マイク文字起こし失敗は、録音が短すぎたり Enter で即停止した場合に発生している。
音声認識の誤認識は、マイク環境やノイズによるもので、Whisper API の入力品質に依存する。
