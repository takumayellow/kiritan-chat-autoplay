読みどころ

  • 描く順番（drawFrame、L411-421）。背景のレーン → 拍と小節の線 → コンボ → ノーツ → 判定線 → 光 → 判定の文字 → スコア → 進み具合。コンボをノーツより先に描くので、大きなコンボの数字が流れてくるノーツを隠しません。
  • drawNotes（L146-190）。譜面の最後のノーツから逆順に描き、手前のノーツが奥のノーツの上に重なるようにしています。ロングノーツは「胴 → 終点 → 始点」の 3 枚重ねです。
  • 時間で動く表示はすべて「今 − 判定した時刻」から計算する（L225、L269、L314）。フレームごとに状態を書き換えるのではなく、毎回その場で経過時間から大きさと透明度を出すので、描画がどれだけ間引かれても正しい見た目になります。
  • noteThickness（L142-144）。ノーツの厚みと判定線の帯の厚みを同じ式で決めています。

落とし穴

  • ロングノーツを最後まで押し切っても、判定の文字は出ず、コンボの数字も弾まない。 src/game/engine.ts の L136 は、終点の perfect では Flash を作りません。一方 src/game/session.ts の finishHold（L123-129）はコンボを 1 増やします。このファイルの光・弾み・判定の文字は Flash だけを見るので、コンボの数は増えても何も動きません。終点の miss は Flash になるので MISS の文字は出ます。
  • 同じ時刻の判定が複数あると、判定の文字は 1 つしか出ない。 latestFlash（L252-259）は atMs がいちばん大きい 1 件を返し、同じ値なら配列の前のほう（先に記録したほう）を残します。オートプレイで和音をまとめて叩いたときや、見逃しが同じフレームで複数確定したときに起きます。叩いたときの光（drawFlashes）はレーンごとに全部描かれます。
  • 一時停止から戻ると、途中の動きが飛ぶ。 一時停止中は nowMs が止めた時刻で固定されます（src/game/engine.ts の L195）。再開すると nowMs は現在の時刻に戻るので、止めている間の時間が一気に経過したことになり、出ていた判定の文字や光は再開した瞬間に消えます。

g.save() は道具の今の設定（色・太さ・影・不透明度・変形など）を棚に預け、g.restore() で預けたときの設定に戻します。一時的に設定を変えて描き、元に戻したいときに使います。 g.shadowColor と g.shadowBlur を設定すると、その後に描く形にぼかした影が付きます。明るい色を指定すると「光っている」ように見えます。影は後の描画にも付き続けるので、save と restore で挟んで、ここだけに効かせます。
