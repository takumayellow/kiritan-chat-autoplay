L3–L9

文法: for...of による繰り返し

for (const ch of id) 文; は、id の中身を先頭から 1 つずつ ch に入れて、文 を繰り返します。id が文字列なら 1 文字ずつ、配列なら 1 要素ずつです。

番号で回す for (let i = 0; i < id.length; i++) と違い、何番目かを気にしなくてよいのが利点です。繰り返す文が 1 つだけなら { } を省けます（L6）。

文法: 符号なし右シフト >>>

a >>> n は、a を 2 進数の 32 ビットの整数とみなして、右へ n ビットずらす演算です。n が 0 のときはずらさないので、「32 ビットの整数に直す」働きだけが残ります。直し方は次のとおりです。

  • 小数部分を捨てる
  • 2^32（4294967296）で割った余りにする
  • 負の数にならない（0〜4294967295 のどれかになる）。たとえば -5 >>> 0 は 4294967291

計算の途中で数がどこまでも大きくならないよう、毎回この範囲に戻すために使われます。

jacketHue(id) は、曲 ID から 0〜359 の数を 1 つ決めます。この数は色相環の角度（0 が赤、120 が緑、240 が青）として使われ、曲ごとに違う色のジャケットになります（src/ui/SongSelect.tsx の L28）。同じ ID からは毎回同じ色が出るので、曲の色は開くたびに変わりません。

L5 の let は、値を入れ直す変数です（src/main.tsx の『const と let』の囲み）。

L6 では、ID の 1 文字ずつに次の計算をします。

  1. ch.charCodeAt(0) — その文字の番号（文字コード）。f は 102、- は 45
  2. hash * 31 + 文字の番号 — それまでの値を 31 倍して、文字の番号を足す
  3. >>> 0 — 0〜4294967295 の範囲に戻す

31 倍してから足すので、同じ文字でも位置が違えば結果に違う重みで効き、ab と ba が別の数になります。

3/** 曲 ID から決まる色相（0〜359）。ジャケットの代わりのグラデーションに使う。 */
4export function jacketHue(id: string): number {
5 let hash = 0;
6 for (const ch of id) hash = (hash * 31 + ch.charCodeAt(0)) >>> 0;
7 return hash % 360;
8}

L10–L15

composerMark(composerEn) は、作曲者の英語名から姓の頭文字を 1 文字返します。ジャケットの真ん中に出す文字です。

L12 は 2 段です。

  1. composerEn.trim() — 前後の空白を取り除く
  2. .split(/\s+/) — 1 つ以上続く空白（/\s+/ は「空白文字が 1 個以上」を表す正規表現、文法の索引の『正規表現』）で区切り、単語の配列にする。"Ludwig van Beethoven" なら ["Ludwig", "van", "Beethoven"]

L13 は 3 段です。

  1. words[words.length - 1] — 最後の単語。"Beethoven"
  2. ?? "" — 無ければ空の文字列にする（文法の索引の『オプショナルチェーン ?. と ??』）
  3. .charAt(0).toUpperCase() — 先頭の 1 文字を取り、大文字にする。"B"

英語名は姓が最後に来るので、最後の単語の頭文字が姓の頭文字です。「Johann Sebastian Bach」は B、「Frédéric Chopin」は C になります。

L13 の ?? "" は、実際には働きません。split は空の文字列からでも [""] という要素 1 つの配列を返すので、最後の要素は必ずあります。それでも書いてあるのは、このプロジェクトの TypeScript の設定（noUncheckedIndexedAccess）が「配列を番号で読んだ値は undefined かもしれない」として扱うからです。?? "" で、型の上でも必ず文字列になります。空の名前を渡すと "" が返ることは、src/ui/select.test.ts で確かめています。

10/** 作曲者の姓の頭文字（"Ludwig van Beethoven" → "B"）。 */
11export function composerMark(composerEn: string): string {
12 const words = composerEn.trim().split(/\s+/);
13 return (words[words.length - 1] ?? "").charAt(0).toUpperCase();
14}

L16–L21

stepIndex(index, delta, length) は、長さ length の一覧で、位置 index から delta だけ動かした位置を返します。delta は上や左へなら −1、下や右へなら 1 です。

  • L18 — 一覧が空なら、行き先が無いので −1 を返す
  • L19 — index + delta を、0 から length - 1 の範囲に収める

L19 は内側から読みます。

  1. Math.max(0, index + delta) — 2 つのうち大きいほう。0 より小さければ 0 にする
  2. Math.min(length - 1, 1 の結果) — 2 つのうち小さいほう。最後の位置より大きければ最後の位置にする
index delta length 答え
0 −1 5 0（先頭で止まる）
2 1 5 3
4 1 5 4（最後で止まる）
0 1 0 −1（一覧が空）

一覧の端で止まり、反対の端へは回り込みません。

16/** 一覧の中で delta だけ動かした位置。端では止める。 */
17export function stepIndex(index: number, delta: number, length: number): number {
18 if (length <= 0) return -1;
19 return Math.min(length - 1, Math.max(0, index + delta));
20}

L22–L26

stepDifficulty(difficulty, delta) は、難易度を easy・normal・hard・expert の並びで delta だけ動かします。

  1. DIFFICULTIES.indexOf(difficulty) — 今の難易度が並びの何番目か。"normal" なら 1
  2. stepIndex(1 の結果, delta, 4) — 動かした位置。端では止まる
  3. DIFFICULTIES[2 の結果] — その位置の難易度
  4. ?? difficulty — 無ければ今の難易度のまま

stepIndex を一覧と難易度の両方に使い回しているので、「端で止める」決まりが 1 か所にまとまっています。4 段目の ?? は L13 と同じく、番号で読んだ値を型の上で必ず Difficulty にするためのものです。

22/** 難易度を delta だけ動かす。端では止める。 */
23export function stepDifficulty(difficulty: Difficulty, delta: number): Difficulty {
24 const index = stepIndex(DIFFICULTIES.indexOf(difficulty), delta, DIFFICULTIES.length);
25 return DIFFICULTIES[index] ?? difficulty;
