# きりたんの会話の設計

きりたんとの会話を長く、自然に続けるための設計をまとめる。実装は `core/kiritan_dialogue.py` と
`core/kiritan_core.py` の `chat_with_history`。キャラクター設定の調査は
[kiritan_persona_research.md](kiritan_persona_research.md) にある。

## 使われる場所

会話の生成は `core.chat_with_history` に一本化した。次のどの経路でも同じ設計が効く。

| 経路 | 入口 | 履歴 |
|------|------|------|
| LINE Bot | `line_bot/server.py` | SQLite（`ChatStore`）に保存した直近20件 |
| GUI（VOICEVOX 読み上げ） | `gui/kiritan_chat_gui_new.py` | 画面を開いている間の会話 |
| CLI（VOICEROID 読み上げ） | `cli/kiritan_chat_cli.py` | 起動している間の直近20往復 |

CLI はこれまで独自の `chat_once` で、システムプロンプトと今回の発言だけを送っていた（履歴なし）。
今回 `chat_with_history` を通すようにしたので、読み上げでも前の話を覚えて会話できる。

## 改善前の会話ログの分析

LINE Bot の会話ログ（利用者5人、98発言、きりたんの返答49件）を集計した。利用者の発言の中身は
ここには載せない。

| 項目 | 件数 |
|------|------|
| 質問で終わる返答 | 24 / 49 |
| 質問を含む返答 | 39 / 49 |
| 質問を含む返答の最長連続 | 12 |
| 「お待ちしています」「何かあれば教えてね」のような締め | 25 / 49 |
| 「あなた」を使った返答 | 16 / 49 |
| 東北・きりたんぽに触れた返答 | 6 / 49 |
| 返答の長さ（文字） | 中央値 54、最大 342 |
| 利用者の発言のうち中身の少ないもの（一文字、呼びかけ、相づち、挨拶） | 30 / 49 |

返答に見られた問題は次のとおり。

1. 毎回の返答を質問で締める。続けて聞かれると、利用者は答えるだけになり、きりたんと話している感じがしない。
2. 質問が漠然としている（「今日はどんな一日？」など）。答えにくく、会話が止まる。
3. 一つの返答に質問が二つ以上ある。
4. 利用者の発言が短いと、「何か話したいことがあれば教えてください。お待ちしています」と話題を投げ返す。
   中身の少ない発言が全体の6割あるので、この返し方が会話を止める一番の原因になっていた。
5. 同じ呼びかけに、まったく同じ返答を返したことがある。
6. 書名と著者のような事実を作る。理大祭の日程や、このチャットが何のためにあるのかを知らない。
7. LINE で番号付きの箇条書きを返す。「こんにちは、あなた」のような不自然な呼びかけ。
8. 東北の話題を不自然に差し込む。
9. 今日の日付や時間帯を知らないので、時間に合った話ができない。

旧プロンプトは「最後に質問を一つ添えて会話を続ける」と指示していた。1〜4はこの指示をモデルが
毎ターン守った結果で、プロンプトの言い回しを直すだけでは直らない。

## 設計

### 方針: 会話は質問ではなく、きりたん自身の話で続ける

人どうしの雑談が続くのは、相手の話を受け止めたうえで自分の話を足すから。質問は、
相手が話したことをもう少し聞きたいときに、ときどき一つ入れれば足りる。
きりたんは「クールで毒舌、夜型でゲーム好き」（公式設定）なので、自分の感想や軽いツッコミを
足す形のほうが、質問を重ねるよりキャラクターにも合う。

この方針を、毎ターンの判断をモデル任せにせず、コードで決める。

### 1. ターンの方針（`plan_turn`）

利用者の発言と直前までの履歴から、今回の返答で何をするか（`TurnPlan`）を決める。

| 動き | いつ | 何をするか |
|------|------|------------|
| answer | 質問された | まず答える。知らないことは分からないと言う |
| react | 自分のことを話してくれた | 具体的に受け止め、きりたんの感想・経験・意見を一つ足す |
| ack | 相づち（なるほど、そっか、わかる、w） | 直前の話題を一歩だけ深める。材料が無ければ前の話からつなげて次の話題へ |
| greet | 挨拶 | 短く返し、時間帯や季節に合った近況を一つ話す |
| offer_topic | 呼びかけや一文字だけ | 話題を求めず、きりたんから話題の種の話を一つする |
| farewell | おやすみ、またね | 短く見送る。引き止めず質問もしない |

質問はターンごとに許可を決める。

- 直前の返答で質問していたら、今回は質問しない（`allow_question = False`）。続けて聞かない。
- 相手が自分のことを話してくれて、直近2回の返答で質問していなければ、具体的な質問を一つしてよいと伝える
  （`suggest_question`）。「質問は入れなくてよい」だけだと、モデルによっては一度も聞き返さなくなるため。
- 質問するときは一つだけ、相手がいま話したことについて、一言で答えられるもの。漠然とした質問はしない。

方針はシステムメッセージにして、**会話履歴の後ろ、今回の発言の直前**に置く。履歴の前に置いた
システムプロンプトの指示は、履歴が長くなると効きにくくなる（旧プロンプトの「質問を添えて」が
毎回守られていた一方、「2〜3文」は守られなかった）。

### 2. 話題の種（`pick_topic_seed`）

利用者の発言が短いとき、きりたんが自分から出す話題。公式設定から作った。

- ゲーム、ずんねえさま・イタコねえさまとの出来事、弓道部の練習、夜ふかしや休日の過ごし方、きりたんぽや秋田の食べ物
- 月ごとの季節の話題（10月は紅葉ときりたんぽ鍋）
- 場ごとの話題（LINE ではメニューの［ゲーム］にある作品）

最近の返答で触れた話題は選ばない。同じ話題が続かないよう、ターンごとに選ぶ順をずらす。

### 3. 場の情報（`situation_note`、`line_bot/context.py`）

モデルが自分では知り得ないことを、方針と一緒に渡す。

- いまの日時と時間帯（朝・昼・夕方・夜・深夜）
- 前回の会話からの間隔（12時間以上あいたとき）
- LINE の場合: このチャットが ITC Prog 班の作ったものであること、きりたんは小学生なので部員ではないこと、
  メニューから遊べる作品の一覧、理大祭の日程（開催前はあと何日、期間中は開催中、終わったら出さない）

### 4. 生成後の整え（`polish_reply`）

方針を渡しても、モデルが守らないことはある。生成後にコードで次を取り除く。

- 末尾の「お待ちしています」「何かあれば教えてね」のような締め
- 質問しないターンの質問。質問してよいターンでも、最後の一つ以外の質問

取り除くと相づちしか残らない短い返答は、そのまま返す。

### 5. 繰り返しの防止（`is_repetitive`、`overused_phrases`）

返答が直近5回の返答のどれかとほぼ同じ（類似度 0.72 以上）なら、「同じような返答をしている」と
伝えて一度だけ作り直す。

返答全体は違っても、同じ言い回しを毎回使うことがある。gpt-5.4-mini は「静かで落ち着きます」を
話題に関係なく何度も使った。一回ずつ見れば自然な文なので、言い回しを禁止リストに書く方法では
モデルが変わるたびに直すことになる。そこで、口癖を会話の中から見つける。

- 直近4回の返答から、漢字で始まりひらがなを含む3〜6文字の言い回しを取り出し、2回以上の返答に
  出てきたものを口癖とみなす（`overused_phrases`）。
- 先頭の漢字の語が利用者の発言や場の情報（日時、時間帯、LINE の説明）に出てくる言い回しは、
  いまの話題なので除く（秋田の話で「秋田の」を繰り返すのは自然）。「思い」「少し」のようなよく使う語も除く。
- 「落ち着」と「落ち着きます」のように重なるものは、より多くの返答で使われたほうを残す。回数が同じなら長いほう。
  短いほうが残れば「落ち着いて」のような活用の違いもまとめて避けられる。
- 見つけた口癖は `TurnPlan.avoid_phrases` に入れ、方針に「今回は使わず、別の言い方や別の話にする」と書く。
- それでも返答に含まれていたら、一度だけ作り直す。作り直しは `is_repetitive` と合わせて一返答に一回まで。

### 6. ペルソナ（`KIRITAN_PERSONA_TEMPLATE`）

調査に合わせて書き直した。

- 年齢を11歳（公式）に直した。旧ペルソナは14歳だった。
- 話し方は、言葉づかいとして書く。「です・ます調」「感想は短く言い切る」「ときどき短いツッコミや皮肉」
  「感嘆符や顔文字はほとんど使わない」「褒められたら短くお礼を言い、次の話に移る」。
- 「落ち着いた」「クール」のような性格を表す言葉は書かない。旧ペルソナの「落ち着いた丁寧語」は、
  モデルが話し方の指定ではなくきりたんの自己像として受け取り、褒められると「落ち着いて見えるなら
  悪くないです」「少し照れます」と自分の性格を説明した。性格は反応の仕方に出すもので、自分で
  説明しないことも書いた。
- 東北の話は自然なときだけ。名前を知らないうちは「あなた」と呼びかけない。
- 守ること: 作り話をしない、政治・宗教・誹謗中傷・性的な話題に乗らない（ガイドラインに合わせた）。
- LINE の出力は普段1〜3文、見出しや太字を使わない。読み上げ（GUI・CLI）は記号や箇条書きを使わない。

### 7. モデル

`/style 1`（既定）を gpt-4o-mini から gpt-5.4-mini（`reasoning_effort: none`）に変えた。下の評価で、
質問の量、締めの定型句、「あなた」の多用、キャラクターらしさのどれもが一番良く、返答も一番速かった。
gpt-4.1-mini は架空の体験（祖母の家に行った、など）を作りやすかった。

より安い gpt-5.6-luna と gpt-5.4-nano も同じ評価で比べたが、gpt-5.4-mini のままにした
（数値は「評価」の節）。

- gpt-5.4-nano は です・ます調 が崩れ（「いいね」「だよ」）、方針の文をそのまま返答に書くことがあった。
- gpt-5.6-luna は質の面では gpt-5.4-mini に近いが、9回の生成のうち5回で、返答の途中にロシア語などの
  文字が混じった（どの回も1件）。LINE でそのまま見えてしまう。返答も 0.4〜0.6 秒遅い。
- 費用は gpt-5.4-mini が 1 返答 約 0.2 円、gpt-5.6-luna が 約 0.05 円。理大祭の2日間で 2000 返答としても
  差は 300 円ほどなので、安さより返答の安定を取った。

`/style 3` に指定されていた o4-mini-high は存在しないモデル名で、毎回失敗して次のモデルに
落ちていたので、o4-mini に直した。モデルが使えないときは `OPENAI_MODEL`（設定されていれば）、
スタイルのモデル、gpt-4o-mini、gpt-4.1-mini、gpt-4o の順に試す。

## 評価

ログに似せた架空の会話7本（中身の少ない発言が続くもの、挨拶から始まるもの、理大祭や作品について
聞くもの、10往復の雑談など、利用者の発言42件）を、旧プロンプトと新設計で生成して比べた。

| 構成 | 質問率 | 最大連続 | 複数質問 | 締め | 「あなた」 | 長さの中央値 | 1返答の時間 |
|------|--------|----------|----------|------|------------|--------------|-------------|
| 旧プロンプト + gpt-4o-mini | 0.90 | 6 | 8 | 13 | 22 | 72字 | 1.0秒 |
| 新設計 + gpt-4o-mini | 0.48 | 1 | 0 | 2 | 9 | 111字 | 1.5秒 |
| 新設計 + gpt-4.1-mini | 0.29 | 1 | 0 | 0 | 3 | 92字 | 1.0秒 |
| 新設計 + gpt-5.4-mini | 0.14 | 1 | 0 | 0 | 0 | 81字 | 1.0秒 |

同じ条件で gpt-5.4-mini をもう一度生成したときの質問率は 0.19 だった。生成ごとに 0.05 程度は揺れる。

- 質問率: 質問を含む返答の割合
- 最大連続: 一つの会話の中で、質問を含む返答が続いた最大の回数
- 複数質問: 一つの返答に質問が二つ以上ある返答の数
- 締め: 「お待ちしています」のような締めを含む返答の数

新設計の gpt-5.4-mini の返答は、相手の話を受け止めてから自分の体験や意見を足す形になり、
質問で締める返答はほぼ無くなった。きりたんらしい軽いツッコミ（夜ふかしを自分で「だめですね」と言う、
1限があるのに続けようとする相手に「寝るほうがまし」と返す、など）も出ている。

### ペルソナと口癖の対策

褒められる会話（「かわいいね」「もちほっぺだ」「しっかりしてるよね」「性格クールって言われない？」
「ほめてるんだよ」）を加えた8本（利用者の発言47件）で、ペルソナを直す前と後を比べた。
「自己説明」は「照れ」「落ち着いて見える／いる」「クール」「毒舌」などで自分の性格を言った返答の数。
「夜は静かで落ち着きます」のような普通の使い方は数えない。

| 構成 | 質問率 | 自己説明 | 長さの中央値 | 1返答の時間 | 1返答の費用 |
|------|--------|----------|--------------|-------------|-------------|
| 旧ペルソナ + gpt-5.4-mini | 0.13 | 4 | 76字 | 1.3秒 | 0.21円 |
| 新ペルソナ + 口癖の対策 + gpt-5.4-mini（2回） | 0.15 | 1 / 0 | 62字 / 61字 | 1.2秒 / 1.1秒 | 0.20円 |
| 旧ペルソナ + gpt-5.6-luna | 0.19 | 3 | 77字 | 1.7秒 | 0.05円 |
| 新ペルソナ + 口癖の対策 + gpt-5.6-luna（2回） | 0.19 / 0.21 | 1 / 2 | 68字 / 66字 | 1.6秒 / 1.5秒 | 0.05円 |

直した後に残った自己説明は、どれも「性格クールって言われない？」と直接聞かれたときの答えか、
その次の返答で相手の言った「クール」を受けたもので、聞かれていないのに自分の性格を言う返答は
無くなった。「少し照れます」も出なくなった。

## テスト

`tests/` に pytest のテストがある（API は呼ばない）。CI（`.github/workflows/linebot_ci.yml`）で実行する。

```bash
python -m pytest -q tests
```
