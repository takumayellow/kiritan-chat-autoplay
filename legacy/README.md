- `kiritan_cli.py` - Basic CLI using SeikaSay2 directly
- `kiritan_chat_gui.py` - Basic GUI controlling VOICEROID via UIA

### v2 (2025-09-15) - GUI Enhancements
- `kiritan_chat_gui_plus.py` - Extended GUI with management commands (/reset, /reload, etc.)

### Current (2025-11 onwards)
- `kiritan_chat_cli.py` - Full-featured CLI with mic input, SQLite profiles, persona system
- `kiritan_chat_gui_app.py` - tkinter GUI wrapping the CLI module
